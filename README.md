## ⚙️ Setup and Deployment

### Running Locally
1. Clone the repository.
2. If you have a local server extension (like Live Server in VS Code), open `frontend/index.html`.
3. To test Supabase integration, ensure the `database/supabaseClient.js` is correctly configured with your environment variables.

### Deploying to Vercel
This project is pre-configured for Vercel. 
1. Connect this repository to your Vercel account.
2. Vercel will automatically detect the `vercel.json` file and handle the rewrites for professional URLs (e.g., `/about` instead of `/about.html`).
